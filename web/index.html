配置 AI 的 Base URL
填写服务商接口地址（OpenAI 兼容协议）。只填到域名即可，程序会自动补全 /v1。
常用示例：OpenAI https://api.openai.com/v1 · DeepSeek https://api.deepseek.com/v1 · 本地 Ollama http://127.0.0.1:11434/v1
填写 API Key
Key 只写入本机 config.json，不会发送到该服务商以外的任何地址。

工具调用限制
控制 Agent 单轮与整个会话最多能调用多少次工具，避免失控循环。
内置工具位于 tools/ 目录，每个工具一个文件夹（含 tools.py 与 tools.md）； 技能位于 skills/ 目录，一个技能一个 md 文件。二者都会整篇嵌入系统提示词。
