# ask_followup_question — 向用户提问

## 作用

当你需要用户做选择、而任何合理默认值都可能带来不可逆后果时，用本工具提出一个结构化选择题。调用后当前任务会**挂起等待**，用户在对话界面点击选项后，工具返回用户的选择，你再据此继续。

## 参数

- `question`（string, 必填）：完整的问题描述，说清背景与你要确认什么。
- `options`（array, 必填）：2-6 个选项，每项为 `{"label": "选项文字", "description": "补充说明（可省略）"}`，也接受纯字符串。
- `multiSelect`（boolean, 可选）：是否允许多选，默认 `false`。
- `timeout`（integer, 可选）：等待用户回答的最长秒数，默认 600，最大 3600。

## 返回

用户选择的选项文字（多选时为多个 label，以「、」连接）；超时则返回提示，此时应基于合理默认值继续，并在最终答复中说明所作假设。

## 注意事项

- 只在**确有必要**时使用：信息不足会导致错误方向、多个合理方案需用户拍板、操作不可逆或高风险。
- 能通过读取代码/文件自行查明的事实不要问；能安全默认化的不要问。
- 一次只问一个问题，选项要互斥且覆盖常见情况，可额外提供一个「其他/由你决定」类选项。
- 用户回答前不要重复提问；超时后继续推进，不要死等。
