# emergency_stop — 紧急停止（治理/人机边界）

## 作用
触发最高优先级的紧急停止：立即中止本轮后续步骤（复用运行时的 stop 识别机制），保留停止说明；用于发现严重风险、操作可能失控或用户要求立即叫停时。

## 参数
- `reason`（string, 必填）：紧急停止原因（发现了什么风险、为何叫停）。
- `preserve_progress`（boolean, 可选）：是否保留已完成的阶段性成果，默认 true。

## 返回
`stop_task` 信号 + 停止说明；运行时会据此结束本轮交互。

## 适用
- 执行中发现不可逆/高风险后果（误删、误部署、数据损坏）。
- 用户明确要「先停下」。
- 与 `request_approval` 的区别：approval 是「执行前确认」，emergency_stop 是「执行中叫停」。
