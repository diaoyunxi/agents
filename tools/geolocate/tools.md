# geolocate — 地理编码/逆地理编码（信息获取）

## 作用
地址↔经纬度互转（Nominatim，免密钥，限流约 1 次/秒）。正查：地址->坐标；反查：坐标->地址。

## 参数
- `address`（string, 正查必填）：地址文本，如 `北京市朝阳区`。
- `lat` / `lon`（number, 反查必填）：纬度/经度。
- `limit`（integer, 可选）：正查最多返回结果数，默认 3。
- `timeout`（integer, 可选）：默认 20 秒。

## 返回
正查：编号地点（显示名 + 坐标 + 类型）；反查：国家/省/市/街道 + 完整地址。

## 注意事项
- 高频调用会被 Nominatim 限流；地点/路线/周边更复杂需求配合地图 API。
