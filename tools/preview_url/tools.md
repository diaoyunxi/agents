# preview_url — 预览 URL

## 作用

在服务器主机的默认浏览器中打开一个 http(s) 链接，用来预览本地页面、本地开发服务或任何网页。

## 参数

- `url`（string, 必填）：完整 URL，必须以 `http://` 或 `https://` 开头，例如 `http://localhost:6573/chat`。

## 返回

打开结果；无图形环境时会说明「未确认」，此时可手动在浏览器访问。

## 注意事项

- 本工具作用于**运行后端的这台机器**的浏览器，不是远端用户的浏览器。
- 只接受 http(s) 协议；本地文件请用 `read_file`。
