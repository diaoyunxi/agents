# write_file — 写入文件

## 作用

把一段完整的文本写入工作区中的文件。如果文件已存在且未显式允许覆盖，工具会拒绝执行并提示你改用 `edit_file`。
每次写入都会在右侧「文件变更」面板中生成一条记录，包含新增/删除行数与统一 diff。

## 参数

- `path`（string, 必填）：目标文件的相对路径，父目录不存在会自动创建，例如 `src/utils/helper.py`。
- `content`（string, 必填）：文件的完整新内容（整体覆盖）。换行请使用真实换行符。
- `overwrite`（boolean, 可选）：文件已存在时是否允许覆盖，默认 `false`。

## 返回

一句话结果，形如：`已新建文件 src/utils/helper.py（32 行, 908 字符）`。

## 注意事项

- `content` 必须是完整的文件内容，不要只写片段；局部修改请用 `edit_file`。
- 路径必须位于工作区内，超出工作区会报错。
- 内容较长时可以分多次写入，或先用 `write_file` 建骨架再用 `edit_file` 补全。
