# read_file — 读取文件

## 作用

读取工作区内某个文件的文本内容，并在返回结果中附带行号，便于你后续精确引用或编辑某几行。
如果传入的路径是一个目录，则返回该目录下的条目清单。

## 参数

- `path`（string, 必填）：相对工作区的文件路径，例如 `src/main.py`。也可以传绝对路径，但必须位于工作区内。
- `start_line`（integer, 可选）：从第几行开始显示，行号从 1 开始。省略时从头开始。
- `end_line`（integer, 可选）：显示到第几行（含）。省略时显示到文件末尾。
- `max_chars`（integer, 可选）：最多返回的字符数，默认 20000。文件很大时请分段读取。

## 返回

纯文本：先是 `文件: 路径 | 总行数: N | 显示范围: a-b` 的头部，随后每行格式为 `行号 | 内容`。

## 注意事项

- 路径越界（超出工作区）会直接报错，此时请改用工作区内的相对路径。
- 文本编码会自动在 utf-8 / gbk 之间回退，二进制文件会返回乱码，请改用 `run_shell` 处理。
- 建议先读取再编辑，避免覆盖已有内容。
