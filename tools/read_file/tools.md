# read_file — 读取文件

## 作用

读取工作区内某个文件的文本内容，并在返回结果中附带行号，便于后续精确引用或编辑某几行。
传入目录时返回该目录下的条目清单；传入图片文件（png/jpg/jpeg/gif/webp/bmp）时，会以**图像内容**的形式返回，供多模态模型直接查看。

## 参数

- `filePath`（string, 必填）：相对工作区的文件路径，例如 `src/main.py`。也可以传绝对路径，但必须位于工作区内。
- `offset`（integer, 可选）：从第几行开始显示，行号从 1 开始。省略时从头开始。
- `limit`（integer, 可选）：最多显示多少行，默认 2000。
- `max_chars`（integer, 可选）：文本最多返回的字符数，默认 20000。文件很大时请分段读取。

## 返回

- 文本文件：先是 `文件: 路径 | 总行数: N | 显示范围: a-b` 的头部，随后每行格式为 `行号 | 内容`。
- 图片文件：`[图片] 路径 | 媒体类型 | 尺寸 | 大小`，并附带 base64 图像数据（超过 1568px 会自动等比缩小）。
- 目录：该目录下的条目清单。

## 注意事项

- 路径越界（超出工作区）会直接报错，此时请改用工作区内的相对路径。
- 文本编码会自动在 utf-8 / gbk 之间回退；二进制文件会返回乱码，请改用 `execute_command` 处理。
- 图片功能依赖 Pillow（`pip install Pillow`）做缩放归一化；未安装时原样返回图片字节。
- 建议先读取再编辑，避免覆盖已有内容。
