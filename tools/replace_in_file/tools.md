# replace_in_file — 精确文本替换

## 作用

在已有文件中做小范围的精确替换：给出待替换原文 `old_string` 与新文本 `new_string`，工具只替换匹配片段，其余内容原样保留。每次修改都会在右侧「文件变更」面板生成 diff 记录。

## 参数

- `filePath`（string, 必填）：目标文件的相对路径，必须已存在。
- `old_string`（string, 必填）：要被替换的原文，必须与文件内容**完全一致**（含缩进、空行）。
- `new_string`（string, 可选）：替换后的新文本；省略或留空表示删除这段内容。
- `replace_all`（boolean, 可选）：是否替换全部出现的位置，默认 `false`。

## 返回

`已编辑 src/app.py（替换 1 处）`；未找到原文时，会返回最接近的行号提示；找到多处相同文本且未指定 `replace_all` 时会拒绝执行，防止误改。

## 注意事项

- `old_string` 必须是精确片段；上下文太长容易失配，建议包含 1~3 行唯一上下文。
- 单次替换建议不超过 50 行，大改动请拆成多次调用。
- 新建文件或整体重写请用 `write_to_file`；删除整个文件用 `delete_file`。
- 修改前不确定现状时，先 `read_file` 确认。
