# think — 结构化思考暂存（元认知）

## 作用
把多步推理、假设、权衡、风险沉淀到工作区 `.think/` 目录（Markdown），便于长任务中记录思考、并在后续步骤用 `review=true` 复核。无副作用，仅写工作区。

## 参数
- `thought`（string, 必填）：要暂存的思考内容。
- `topic`（string, 可选）：这条思考所属的主题/步骤。
- `review`（boolean, 可选）：为 `true` 时只回读最近一条，不写入。

## 返回
已暂存的文件名与条数；或 `review=true` 时回读最近一条。

## 适用
复杂决策、调试前的假设验证、方案权衡时留痕，避免「上下文腐烂」。
