# tool_search — 按任务语义检索工具（元工具）

## 作用
在工具名与说明上做轻量关键词检索，返回最相关的若干工具。当内置工具数量较多、不确定该用哪个时用它快速定位。

## 参数
- `keywords`（string, 必填）：空格分隔的关键词，如 `搜索 新闻`、`file diff`、`deploy`。
- `limit`（integer, 可选）：最多返回条数，默认 8。

## 返回
按相关度排序的工具列表（已启用的略优先），停用工具会标注。

## 注意
这是「语义近似」检索（关键词打分），不是向量检索；精确找工具名用 `tool_list` / `tool_describe`。
