# list_dir — 列出目录

## 作用

查看工作区内某个目录下的文件与子目录，用于了解项目结构、确认文件是否存在、定位待修改的模块。

## 参数

- `path`（string, 可选）：目录路径，相对于工作区根目录；省略或传 `.` 表示根目录。
- `recursive`（boolean, 可选）：是否递归列出所有子目录内容，默认 `false`。
- `extension`（string, 可选）：按扩展名过滤，例如 `.py` 或 `py`；省略则不过滤（目录始终显示）。
- `max_entries`（integer, 可选）：最多返回的条目数，默认 300。

## 返回

文本清单，目录以 `name/` 表示，文件带字节数；子目录按缩进体现层级；末尾给出工作区根目录绝对路径。

## 注意事项

- 目录不存在时返回错误提示。
- `.git`、`node_modules`、`__pycache__`、虚拟环境目录等会被自动跳过。
- 不确定文件在哪时，先用本工具定位，再用 `read_file` 读取。
