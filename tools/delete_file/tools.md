# delete_file — 删除文件

## 作用

删除工作区中的一个文件。删除操作不可恢复，执行前会在右侧「文件变更」面板留下 delete 记录（含被删内容预览）。

## 参数

- `filePath`（string, 必填）：目标文件的相对路径，必须已存在。

## 返回

`已删除文件 temp/old.py`；目标是目录、路径不存在或越界时返回错误。

## 注意事项

- 只能删除文件；目标是目录时会拒绝并提示改用 `execute_command`。
- 不能删除工作区根目录。
- 删除前请确认该文件不再需要；不确定内容时先 `read_file`。
- 批量删除请谨慎，优先使用 `execute_command` 并自行确认清单。
