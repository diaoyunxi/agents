# read_rules — 加载可请求的规则

## 作用

按需加载规则文档。规则是放在 `.agents/rules/` 下的 md 文件（按「工作区优先、项目目录其次」发现），可带 front-matter：

```
---
name: 前端规范
description: React 组件与样式约定
when_to_use: 创建或修改 web/ 下组件时
---
正文……
```

不带参数调用时列出全部可用规则及其键；带 `ruleNames` 时返回对应规则的完整内容。

## 参数

- `ruleNames`（array<string>, 可选）：要加载的规则键，可以是绝对路径、`name` 或文件名（可省略 `.md`）。省略时只列出可用规则。

## 返回

列出模式：规则名 + 键 + 描述清单；加载模式：每个规则的完整正文，含 `===== 规则 xxx =====` 分隔头。

## 注意事项

- 只在任务确实与某条规则相关时加载，避免用无关规则占满上下文。
- 规则键不存在时会明确提示，并说明如何重新列出可用规则。
