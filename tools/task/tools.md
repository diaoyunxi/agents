# task — 启动子代理

## 作用

启动一个独立的子代理去执行一类任务，并把最终结果返回给你。子代理拥有自己的上下文窗口，适合把「大范围探索」与「主線推进」解耦：主代理不被中间过程占满，子代理汇总关键发现回来。

当前内置：

- `code-explorer`：只读代码库探索专家。可用 `list_dir` / `search_file` / `search_content` / `read_file` 定位实现、梳理调用链、回答问题，返回带 `文件路径:行号` 证据的结论。

## 参数

- `subagent_type`（string, 必填）：子代理类型，目前仅 `code-explorer`。
- `description`（string, 必填）：一句话说明任务是什么（3-5 词），如「定位鉴权实现」。
- `prompt`（string, 必填）：给子代理的完整指令：要查什么、重点文件/目录、返回格式。

## 返回

`[子代理 code-explorer 结果]` 加子代理的最终结论文本。

## 注意事项

- 子代理与主代理共用同一 AI 提供商与模型；探索型任务优先交给 `code-explorer`，需要改文件/跑命令的活儿留在主代理做。
- `prompt` 里写清验收标准（例如「给出入口文件与关键函数所在行」），子代理只汇报与任务相关的发现。
- 子代理是只读的：任何修改都必须回到主代理用 `replace_in_file` / `write_to_file` 完成。
