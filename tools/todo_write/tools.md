# todo_write — 任务清单管理

## 作用

创建或更新当前会话的任务清单，把多步骤工作拆成可跟踪的任务项，随时反映进度。适合 3 步以上的复杂任务：先规划，再逐项完成并更新状态。

## 参数

- `todos`（array, 必填）：任务清单，**全量提交**。每项：
  - `id`（string, 可选）：任务唯一标识；更新既有任务时提供，新建可省略（自动生成）。
  - `content`（string, 必填）：任务内容，动词开头，清晰可执行。
  - `status`（string, 必填）：`pending`（未开始）/ `in_progress`（进行中）/ `completed`（已完成）/ `cancelled`（已取消）。

## 返回

更新后的完整清单（带状态标记）与各状态统计。

## 注意事项

- 同一时刻只应有一个 `in_progress`；完成一项立即标记 `completed`，再推进下一项。
- 计划变化时直接重排/改写清单，旧条目未列出时会保留，可用 `cancelled` 废弃。
- 清单是会话级的，用于帮你和用户对齐进度，不要用来记录琐碎步骤。
