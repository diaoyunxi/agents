# create_plan — 创建任务计划（编排）

## 作用
为复杂任务创建结构化执行计划（目标 + 有序步骤），落盘到工作区 `.plan/<plan_id>.json`，供 `update_plan` 逐步推进、用户随时查看。

## 参数
- `goal`（string, 必填）：一句话任务目标。
- `steps`（array, 必填）：有序步骤，每项 `{"desc": "做什么", "why": "为何(可选)"}`。

## 返回
计划 ID、落盘路径、渲染后的步骤清单；提示用 `update_plan(plan_id=...)` 推进。

## 适用
多步骤任务开始时先建计划，再逐步执行；比 ad-hoc 推进更可审计、不易偏离。
