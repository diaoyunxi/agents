# write_to_file — 写入文件

## 作用

把一段完整的文本写入工作区中的文件：文件不存在则创建（父目录自动创建），已存在则**整体覆盖**。每次写入都会在右侧「文件变更」面板生成一条记录，包含新增/删除行数与统一 diff。

## 参数

- `filePath`（string, 必填）：目标文件的相对路径，例如 `src/utils/helper.py`。
- `content`（string, 必填）：文件的完整新内容（整体覆盖）。换行请使用真实换行符。

## 返回

一句话结果，形如：`已新建文件 src/utils/helper.py（32 行, 908 字符）`。

## 注意事项

- `content` 必须是完整的文件内容，不要只写片段；只想改动局部请用 `replace_in_file`。
- 覆盖已有文件前，建议先 `read_file` 了解现状，以免丢失重要内容。
- 路径必须位于工作区内，超出工作区会报错。
- 内容较长时可以分多次写入，或先用 `write_to_file` 建骨架再用 `replace_in_file` 补全。
