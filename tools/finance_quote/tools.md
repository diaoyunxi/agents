# finance_quote — 金融行情/汇率（信息获取）

## 作用
查询货币汇率（免密钥 `open.er-api.com`）。对股票/加密货币等深度行情，给出可操作的获取方式（配置专用 API 或用 `http_request` 带密钥调用）。

## 参数
- `base`（string, 可选）：基准货币 ISO 代码，默认 CNY。
- `symbols`（string, 可选）：目标货币，逗号分隔，如 `USD,EUR,JPY`。
- `query`（string, 可选）：其它查询意图（如股票代码），用于提示获取方式。
- `timeout`（integer, 可选）：默认 15 秒。

## 返回
基准货币对各目标货币的汇率（含更新时间）。

## 注意事项
- 免密钥接口仅覆盖货币汇率；实盘/高频行情需配置专用 API。
- 引用价格请带更新时间，避免陈旧数据。
