## 内置工具

工具由 `tools/loader.py` 自动发现（每个 `tools/<名>/` 含 `tools.py` + `tools.md`）。
**部分工具声明 `REQUIRES`（能力门控）**，由 `capabilities.py` 探测本机硬件/已装依赖后自动启用或停用，
详见 [13 · 按硬件自动启用](13-按硬件自动启用.md)。用户仍可用 `config.json` 的 `tool_toggles` 显式覆盖。

### 文件与代码

| 工具 | 用途 |
| --- | --- |
| `list_dir` | 列出目录内容（可递归、按扩展名/通配符过滤） |
| `search_file` | 按通配符模式递归搜索文件/目录名 |
| `search_content` | 基于 ripgrep 的文件内容搜索（无 rg 时用内置引擎，尊重 .gitignore） |
| `read_file` | 读取本地文件（文本带行号；图片以图像内容返回给多模态模型） |
| `replace_in_file` | 精确文本替换编辑文件 |
| `write_to_file` | 写入/覆盖整个文件 |
| `delete_file` | 删除文件（高风险） |
| `diff_compare` | 比较两个文件/文本差异（unified diff） |
| `document_read` | 读取多格式文档为文本：PDF(需pypdf)/DOCX(需python-docx)/Markdown/代码/文本 |
| `document_extract_tables` | 从 CSV/TSV/XLSX 提取表格（XLSX 需 openpyxl） |
| `execute_command` | 执行 Shell/PowerShell 命令（高风险） |
| `git_ops` | Git 仓库操作（门控 `cli:git`） |
| `code_search` | 按关键词搜代码（local 复用 search_content；github 给检索链接） |

### 感知与信息获取

| 工具 | 用途 |
| --- | --- |
| `web_search` | 通用网页搜索（默认 DuckDuckGo，可配 Brave/Tavily） |
| `web_fetch` | 抓取网页内容并转换为 Markdown |
| `news_search` | 新闻搜索（默认 DuckDuckGo News 免密钥） |
| `academic_search` | 学术文献检索（默认 arXiv，可配 PubMed） |
| `wikipedia_lookup` | 维基百科条目查询（免密钥，多语言） |
| `rss_read` | 读取 RSS/Atom 订阅源 |
| `weather_query` | 天气/预报查询（Open-Meteo 免密钥） |
| `finance_quote` | 货币汇率（免密钥接口）；深度行情给获取指引 |
| `geolocate` | 地理编码/逆地理编码（Nominatim 免密钥） |
| `http_request` | 发起任意 HTTP 请求（自定义方法/头/体） |
| `translate_text` | 文本翻译（默认 MyMemory 免密钥，可配自定义 API） |

### 执行与操作

| 工具 | 用途 |
| --- | --- |
| `python_execute` | 执行 Python 代码（受限超时，高风险） |
| `javascript_execute` | 执行 JS/Node 代码（门控 `cli:node`，高风险） |
| `sandbox_execute` | 隔离沙箱执行（默认断网+临时目录，高风险） |
| `calculator` | 数学表达式安全求值（AST 白名单，免依赖） |
| `symbolic_math` | 符号计算/方程求解（门控 `pkg:sympy`） |
| `data_analyze` | 表格数据清洗/统计/透视（门控 `pkg:pandas`） |
| `chart_generate` | 生成折线/柱状/散点/饼图 PNG（门控 `pkg:matplotlib`） |
| `qr_generate` | 生成/解析二维码（门控 `pkg:qrcode`） |
| `docker_manage` | Docker 容器/镜像/Compose 管理（门控 `cli:docker`，高风险） |
| `report_generate` | 生成结构化 Markdown 报告并落盘 |
| `knowledge_base_search` | 本地知识库关键词检索/写入（SQLite，免外部向量库） |

### 治理、安全与人机边界

| 工具 | 用途 |
| --- | --- |
| `ask_followup_question` | 向用户提结构化选择题并等待回答 |
| `request_approval` | 高风险操作人工审批门控（挂起等待批准/拒绝） |
