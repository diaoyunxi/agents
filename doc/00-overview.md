# Agents · 本地智能体工作台

一个用 Python 后端驱动的本地 AI Agent。Web 端只负责展示，所有真实能力（AI 调用、工具执行、MCP、配置、文件读写）都实现在后端。

- 监听端口：`6573`（可在 `config.json` 中修改）
- 访问地址：<http://localhost:6573/>
- 默认账号：`root` / `root`（首次登录后可在设置页修改）
