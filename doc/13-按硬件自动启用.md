## 13 · 按硬件自动启用（能力门控）

工具有的可能依赖特定硬件或已安装软件（如 `git`、`node`、`docker`、NVIDIA GPU、某些 Python 库）。
本机制由 Python 在运行时**自动探测本机能力**，据此决定哪些工具**默认启用 / 默认停用**，无需手工配置。

### 探测层：`capabilities.py`

项目根目录的 `capabilities.py` 提供：

- `has(tag)`：判断单个能力标签是否满足。
- `requires_satisfied(requires)`：判断一组标签是否全部满足，返回 `(是否满足, 缺失列表, 可读原因)`。
- `summary()` / `describe()`：本机能力快照（平台、Python、CPU、内存、GPU、已装包、可用 CLI），带缓存，可 `refresh()` 重置。

支持的能力标签：

| 标签 | 含义 | 示例 |
| --- | --- | --- |
| （无） | 总是可用 | — |
| `win` / `posix` / `macos` | 操作系统 | `win` |
| `pkg:NAME` | 可导入的 Python 包 | `pkg:pandas` |
| `cli:NAME` | PATH 中可执行的命令行 | `cli:git` |
| `gpu:nvidia` | NVIDIA GPU（`nvidia-smi` 或 CUDA 可用） | `gpu:nvidia` |
| `cpu_count:N` | 至少 N 个逻辑 CPU | `cpu_count:8` |
| `mem_gb:N` | 至少 N GB 内存（无法判定时不据此关停） | `mem_gb:4` |

### 声明层：工具 `tools.py` 的 `REQUIRES`

工具在自己目录的 `tools.py` 里声明所需能力标签：

```python
NAME = "symbolic_math"
REQUIRES = ["pkg:sympy"]   # 未装 sympy 时本工具自动停用
def run(...): ...
```

`tools/loader.py` 在 `discover()` 时对每个工具调用 `requires_satisfied`，
把 `capability_ok` / `capability_missing` 写进注册表。

### 启用决策（优先级从高到低）

1. **`config.json` 的 `tool_toggles[name]`**：用户显式 `true`/`false` 覆盖，最高优先。
2. **未显式设置时**：按「按硬件自动启用」——工具声明的 `REQUIRES` 能力不满足则**自动停用**，满足则默认启用。

因此：装了 `git`/`node`/`docker`/`pandas`/`qrcode` 的本机，对应工具自动启用；
没装 `sympy`/`matplotlib` 时，`symbolic_math`、`chart_generate` 自动停用（调用会给出安装指引）。

### 查看与验证

- `tool_list` 工具：列出全部工具并标注「启用 / 停用(缺能力)」及各自缺什么。
- `tool_describe`：查看单个工具的 `REQUIRES` 与当前状态。
- 直接运行：`python capabilities.py` 打印本机能力清单。

### 设计边界

- 只做「硬件 / 已装依赖」层面的门控，**不**把「网络是否通」当作硬件；联网工具离线时在调用期给出明确错误，而非被静默关停。
- 缺 `REQUIRES` 的工具（如纯标准库/`httpx`）默认总是可用。
- 探测结果有进程级缓存；依赖变化后调用 `capabilities.refresh()` 或在设置页重新加载即可。
