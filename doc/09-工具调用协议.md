## 工具调用协议

请求模型时优先携带 `tools` 字段（OpenAI function calling）；不支持函数调用的模型仍可降级为在正文输出 JSON：

```json
{"tool": "read_file", "arguments": {"filePath": "README.md"}, "thought": "读取说明文件"}
```

- 一次回复允许输出多个 JSON，后端会依次执行
- 非工具调用的花括号必须转义为 `/{` 与 `/}`，后端会自动还原
- 允许在 JSON 之前输出描述性文字

## 刷新后继续工具上下文

前端会把每一轮 assistant 的 `tool_calls` 与 `tool_results` 持久化到 `chat/*.json`。  
继续旧对话时，`agent_runtime` 会把这些记录重新组装成 OpenAI 的 `assistant.tool_calls` + `tool` 消息，避免刷新浏览器后模型丢失「刚刚读过/写过哪些本地文件」的上下文。
