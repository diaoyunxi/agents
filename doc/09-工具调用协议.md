## 工具调用协议

请求模型时**不携带 tools 字段**，而是在 system 提示词中要求模型通过正文输出 JSON：

```json
{"tool": "read_file", "arguments": {"path": "README.md"}, "thought": "读取说明文件"}
```

- 一次回复允许输出多个 JSON，后端会依次执行
- 非工具调用的花括号必须转义为 `/{` 与 `/}`，后端会自动还原
- 允许在 JSON 之前输出描述性文字
